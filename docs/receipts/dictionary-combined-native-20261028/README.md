For each of Tai Le U+1950 and Han U+6F22, the fixture set an isolated X11 clipboard; real Ctrl+V pasted the scalar at the document end; the driver returned to the start, selected the first four UTF-16 units and used Ctrl+Z. Text length, selection and undo checks passed. These are actual X11 keyboard and clipboard events, not real IME composition.

In the conservative localized control, Tai Le paste changed the logical caret rectangle for prefix UTF-16 offset 4 from `[0,26,1,26]` to `[32.879997,0,1,26]`; undo restored it.
