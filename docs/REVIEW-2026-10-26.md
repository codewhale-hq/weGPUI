## Validation

The [publication receipt](receipts/review-publication-20261026/README.md) contains command logs,
source/image hashes, native fixtures, consumer provenance and the final capture summary.

- Five Rust gates pass on the final Rust source: formatting, locked/offline all-target build,
  59 library tests with three ignored doc examples, strict Clippy and strict rustdoc.
- Three separate gallery geometry/transform tests pass.
- Extracted text harnesses pass: seven word-break cases, 16+4 logical-wrap cases, eight
  trailing-space cases and thirteen CJK cases. Their documented negative controls remain failures.
- All 33 script tests and five website tests pass after the review fixes.
- Footer wrapping passes eight appearance modes, zero target overlap and 96 exact callbacks.
- The README consumer passes a locked/offline build after generating its application lockfile;
  shared dependency versions match the repository. Native pointer/keyboard operation confirms
  modal isolation, Tab/Shift+Tab containment, Escape, focus restoration and counts 0→1→2.
- Final paired capture completes all 1,056 pairs with zero reference page errors; 305 source
  files and 2,112 image hashes match. Against the prior source, 1,055 native images are byte-identical.
  The single native difference is a 59→60 countdown sample; 31 browser differences are spinner
  phases. All changed-image crops were inspected and retained. This reviews the publication
  delta; it does not accept every underlying native/reference difference or establish full parity.

The owner’s original commit convention requires `[skip ci]` subjects. Local checks are not
